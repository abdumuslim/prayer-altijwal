# Iraqi prayer-time image archive

Coverage: **2025-08-11 through 2026-08-11**, one primary image per Gregorian date.
Facebook also posted an identical copy of the 18 December card under a second photo ID; both originals
are retained, and the later copy is marked `calendar_role=duplicate` in the manifest.

The archive intentionally uses a transparent fallback order:

1. Original image posted by the Iraqi Sunni Endowment Facebook page during the covered period.
2. Original image from the same Gregorian month/day in the prior year, visually verified from the printed date.
3. A generated card using the project's digitized official poster values when an exact table exists.
4. A generated card using the project's calibrated nationwide Iraqi Waqf model when Facebook did not publish a usable card. Validation of that model is 99.4% within one minute of the official tables.

Generated cards say `بطاقة تعويضية` at the bottom so they cannot be mistaken for downloaded Facebook artwork.

See `manifest.csv` or `manifest.json` for each date's source type, original Facebook photo ID, source-card date, dimensions, byte count, and SHA-256 checksum.
